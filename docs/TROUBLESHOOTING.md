# Nightfall RC3 beta — troubleshooting

For the first public beta use Ubuntu 24.04 x86-64, a compatible NVIDIA driver,
and the real miner archive asset from GitHub Releases.

## “SYNCING_SAFE_WAIT” or no mining

```bash
/opt/nightfall-miner/minerctl status
/opt/nightfall-miner/minerctl doctor
/opt/nightfall-miner/minerctl fastsync-info
/opt/nightfall-miner/minerctl canonical-check 180 3
```

This is normally the canonical-chain guard waiting for sufficient peers,
current chain height or consistent network state. Give it time to recover.
Do **not** disable the guard, assume an untrusted snapshot is valid, or force
mining on an unverified chain.

## CUDA worker unavailable or architecture mismatch

```bash
nvidia-smi
python3 /opt/nightfall-miner/cuda_workers.py --verify-devices all
```

Check the NVIDIA driver, GPU visibility (`CUDA_VISIBLE_DEVICES`), the exact
compute capability and the matching packaged native worker. RC3 intentionally
rejects unsupported SM versions and tampered worker hashes; there is no PTX
fallback or CUDA source in the user package. Restore a verified archive or
report the GPU model and driver version.

## Wrong GPU, multiple GPUs or batch too large

Look at `/opt/nightfall-miner/minerctl hardware` and the installer's plan.
GPU IDs are *CUDA logical indices*. If you use `CUDA_VISIBLE_DEVICES`,
keep the same setting during installation and service startup.
Multiple GPU models have different VRAM budgets. A mixed physical rig is
experimental until more real hardware results are available.

## “GLIBC_2.39 not found” with --use-prebuilt

The inherited prebuilt `nightfalld` is not supported by the first-beta
prebuilt path on Ubuntu 22.04 or Debian 12. Use recommended Ubuntu 24.04,
or follow the separate **experimental** Core source-build workflow after
checking that all required dependencies are available. Installing/upgrading
glibc manually inside a working rental image is **not recommended**.

## Download checksum failure

Stop installation. Download the approved asset and matching checksum again
from the official GitHub Release. A checksum mismatch is not an option to
ignore. Do not use GitHub's autogenerated “Source code” archives.

## Hashrate lower than expected

Compare **raw** versus **effective** GPU hashrate. Effective speed decreases
when work is interrupted by chain-tip changes, cancellation or canonical
holds. Review the status/guard logs, power limits, memory clocks, thermal
behavior, batch size and GPU utilization before concluding a CUDA regression.
The website benchmark table is not a performance guarantee.

## Fee display

Ordinary-user GPU work carries a 4.5% developer fee. CPU work carries 0%.
The developer fee is accounted by work, not guaranteed to equal exactly
4.5% of found blocks over a short period.

```bash
/opt/nightfall-miner/minerctl dev-fee-status
```

Never post seed phrases, private keys, API tokens, passwords, wallet recovery
files or other credentials in an issue report.

## Issue reports

Open an issue at
https://github.com/Larppak/Nightfall-GPU-Miner/issues
with OS version, NVIDIA driver, GPU model, package version, exact error,
`minerctl doctor` results with private details redacted, whether `--use-prebuilt`
was selected, and whether FastState was imported. Do not post private chain
snapshots or credentials.
